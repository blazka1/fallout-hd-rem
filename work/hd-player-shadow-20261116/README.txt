Мужской персонаж Vault 13: проба контактной тени, 16 ноября 2026

Статус: отдельная рабочая сборка CE, проверена в пещере. В общий runtime
не установлена. Запуск из корня: Start-Fallout-HD-Player-Shadow.cmd.
Запускает новую тестовую игру у входа в пещеру; F11 — HD/оригинал.
Не запускать одновременно с другим Fallout.

Результат
- Мягкая контактная тень под ногами: 6 направлений стойки, 48 кадров ходьбы.
- Тень вычисляет рендерер на отдельном слое. PNG/F1HD костюма, позы,
  метаданные и исходные FRM не редактировались. ImageGen/ComfyUI не запускались.
- Одинаковая опорная форма для всего цикла, без независимой генерации кадров.
  Овал 34 x 14 логических пикселей, смещение от опоры (-1, -2), плавное
  квадратичное затухание, максимум alpha 90/255 (около 35%). Расчёт в x4.
- Затемняется только зарегистрированный HD-пол; камни, стены, скелет,
  предметы и персонажи сохраняют свой цвет. Костюм компонуется поверх тени.
- Это приближение контактной тени, а не направленная физическая тень от
  конкретной лампы и не реконструкция объёмной модели из нового гайда.

Основа
Скопированы фактические source и data/art из актуальной сборки, включая
новые стены, крыс, предметы и HUD. На начало работы установленный EXE:

Проверки

build/hd-player-shadow-20261116/v2: экспериментальный EXE, 392 PASS, 0 FAIL.
Отчёты разных прогонов не суммировать как один тест.
В каждом из 54 ракурсов/кадров проверены изменения только ближнего пола,
неизменность HUD, обратимое выключение и отсутствие накопления затемнения.
Сравнение с установленным EXE: при выключенной тени 54/54 кадра идентичны.
Также проверены настоящий CE-переход по нескольким гексам, отсутствие следа,
перекрытия, свет/затемнение, F11, частичная перерисовка за границей FRM,
скрытие штатным obj_turn_off, скроллинг, пересоздание SDL-текстур и 4K.
Проверены сохранность 40000 ячеек проходимости, HP/AP и инвентаря.
1691 общий файл сверяется review.py; изменения вне компонента не вносились.

Первый прогон v1 сохранён честно: 391 PASS, 1 FAIL. Причина была в новом
тесте: прямое OBJECT_HIDDEN обходило штатную инвалидацию света и области
прозрачности стен. Исправлен тест на obj_turn_off/obj_turn_on, код отрисовки
после v1 не менялся. Изображения для передачи — из успешного прогона v2.

Воспроизводимость
build.ps1 -Jobs 6 — сборка из source с существующими зависимостями, без сети.
test.ps1 -Version <новое-имя> — установка EXE только в runtime этого компонента
  и тест штатным work/hd-player-male/tools/test-player.ps1.
review.py <имя> — сверка кадров и общих хешей, упаковка PNG/GIF/lossless WebP.
  Использует существующий ComfyUI standalone-env/python.exe (Pillow).
source-changes.patch — изменения относительно свежей общей базы.
integration.json — хеши и проверенный статус этой пробы.

Тень переключается через [remaster] hd_player_shadow=0/1.
Пробный ярлык принудительно включает её. Поддержка остаётся ограниченной
мужским безоружным игроком hmjmps в стойке/ходьбе на V13ENT; прочие действия
и состояния используют прежний fallback. Для переноса в общий runtime
потребуются сверка его свежих исходников и минимальное объединение изменений.
