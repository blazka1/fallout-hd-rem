# Fallout 1 CE HD Remaster

Экспериментальный **2D HD-ремастер Fallout 1 на Fallout 1 Community Edition**. Сохраняет игровую логику и изометрическую структуру оригинала; добавляет отдельную HD-отрисовку меню, окружения первой пещеры, выбранных предметов и персонажей. Godot в текущей реализации не используется.

**Исходники Fallout 1 CE в этом репозитории изменены проектом Fallout HD Remaster.** Это модифицированная версия, а не неизменённая копия upstream. Исходный проект: [alexbatalov/fallout1-ce](https://github.com/alexbatalov/fallout1-ce). Существующие лицензии и уведомления авторов сохранены в обоих деревьях CE и в `third_party`.

## Что находится в Git

- `work/hd-world-pilot/fallout1-ce-main/` — основной модифицированный движок с HD-миром.
- `fallout1-ce-main/` — отдельная ветка исходников меню, которую используют существующие скрипты первоначальной сборки зависимостей.
- `scripts/`, `tools/asset-pipeline/`, лёгкие инструменты в `work/` — сборка, экспорт, подготовка ассетов, проверки и обслуживание.
- `assets/hd/` — только лёгкие текстовые описания, workflow и реестры выбранных пакетов; изображения не включены.
- `AGENTS.md`, `HD-TEXTURE-GUIDE.md`, `INVENTOTY_ITEM_CREATE.md` и другие руководства — решения и опыт проекта.

**Не включены:** оригинальная игра и DAT/FRM, сырые и сгенерированные изображения, HD-пакеты графики, веса моделей, Blender-файлы, runtime, EXE/DLL, build, бэкапы, окружения и кэши. Небольшие иконки и другие ресурсы `os/`, поставляемые с исходниками CE, сохранены для сборки приложения.

Клон позволяет собрать код, но сам по себе не содержит готовой игры или нынешнего художественного набора. Для запуска нужны собственные игровые данные Fallout 1; для воспроизведения HD-вида нужны локальные выбранные пакеты. Ссылки на отсутствующие картинки и отчёты в исторических манифестах не означают, что эти файлы опубликованы.

## Сборка в Windows

Нужны Git, Visual Studio 2022 Build Tools с MSVC x64 и Windows SDK, CMake, PowerShell. Python 3.10+ нужен для утилит экспорта; исходные экспортёры используют стандартную библиотеку. ComfyUI требуется только для генерации графики, а не для сборки или запуска EXE.

В корне клона:

```powershell
.\scripts\build-dependencies.ps1 -Component Fallout
.\work\hd-world-pilot\tools\build.ps1
```

Первый шаг скачивает и собирает зависимости, заполняя `build/fallout1-ce/_deps`. Второй использует эти исходники зависимостей офлайн и собирает текущий HD-движок. Поэтому оба небольших дерева CE оставлены в репозитории. Результат: `build/hd-world-pilot/msvc/RelWithDebInfo/fallout-ce.exe`.

Не запускайте старые установщики пакетов поверх существующей игры автоматически. Подготовка runtime требует локальных DAT и выбранных ассетов; некоторые исторические сценарии содержат пути исходной машины или ссылаются на исключённые снимки экспериментов. Сначала прочитайте их параметры и актуальную запись компонента. Основной локальный запуск — `Start-Fallout-HD-World-Pilot.cmd`, когда runtime уже подготовлен.

## Работа с проектом

Начните с [AGENTS.md](AGENTS.md) и [HD-TEXTURE-GUIDE.md](HD-TEXTURE-GUIDE.md). Исторические разделы описывают конкретные версии; текущее состояние компонента сверяйте с его `task.json` и живыми файлами.

После завершения проверок используйте `scripts/complete-build-check.ps1`: он сохраняет PNG и отчёты, проверяет пиксели перед удалением BMP и управляет зарегистрированными результатами/бэкапами. Для вложенной серии очистка выполняется после всех сравнений. Правила — раздел 15 AGENTS.md.

`.gitignore` предназначен для лёгкого исходного репозитория. Не обходите его через `git add -f` для игровых данных, изображений, моделей или сборок. Перед новым коммитом проверяйте состав и размер файлов; неизвестные бинарные форматы игнорируются по умолчанию.
